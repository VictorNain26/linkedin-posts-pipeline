# Variables d'environnement requises (dans .env, mode 600) :
# - ANTHROPIC_API_KEY        : génération des posts (Sonnet + Haiku)
# - LI_CLIENT_ID/SECRET      : OAuth LinkedIn app
# - LI_ACCESS_TOKEN/REFRESH  : tokens utilisateur (générés via oauth_setup.py)
# - LI_PERSON_URN            : URN du compte LinkedIn de Victor
# - GMAIL_SENDER             : adresse Gmail d'envoi du rapport hebdo
# - GMAIL_APP_PASSWORD       : mot de passe d'application Google (Gmail SMTP)
#                              voir https://support.google.com/accounts/answer/185833
